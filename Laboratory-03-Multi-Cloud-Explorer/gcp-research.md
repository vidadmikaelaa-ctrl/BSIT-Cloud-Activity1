# Google Cloud Platform (GCP) Research

## Brief Overview
GCP is Google's cloud platform, launched in 2008. It runs on the same infrastructure powering Google Search, YouTube, and Gmail. It is the leader in AI, machine learning, and containers.

## Global Infrastructure
**34 regions** with one of the world's largest private fiber networks.

## Cloud Management Console
Manage all services at **console.cloud.google.com**

## Four Core Services
1. **Google Compute Engine** — Virtual machines
2. **Google Cloud Storage** — Fast, reliable storage
3. **Google Kubernetes Engine (GKE)** — Manage containers
4. **Vertex AI** — Build and use Artificial Intelligence

## Three Advantages
1. Best AI and machine learning tools
2. Invented Kubernetes — industry standard
3. Fast, modern, and cost-efficient

## Typical Enterprise Use Cases
- AI research and data science
- Modern apps using containers
- Tech startups and innovative projects
