# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform is Google's cloud service, launched in 2008. It runs on the same powerful infrastructure that powers YouTube, Google Search, and Gmail. GCP is famous for AI, machine learning, and containers.

## Global Infrastructure
GCP has **34 regions** worldwide. It owns one of the largest private fiber-optic networks in the world — making it very fast.

## Cloud Management Console
Manage services at `console.cloud.google.com`. It has a clean, simple interface.

## Four Core Services
1. **Google Compute Engine** — Virtual machines in the cloud
2. **Google Cloud Storage** — Safe, low-cost storage for any file type
3. **Google Kubernetes Engine (GKE)** — Automatically manage software containers
4. **Vertex AI** — Tools to build and use Artificial Intelligence

## Three Advantages
1. The best platform for Artificial Intelligence and Machine Learning
2. Invented Kubernetes — the industry standard for containers
3. Very fast, modern, and cost-efficient

## Typical Enterprise Use Cases
- Artificial Intelligence and data science projects
- Modern apps built with containers and microservices
- Tech startups and innovative new businesses
