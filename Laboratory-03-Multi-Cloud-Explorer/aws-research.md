# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's largest and oldest public cloud platform. Launched by Amazon in 2006, it offers over 200 services including computing, storage, databases, AI, and networking. It serves startups, governments, and global enterprises.

## Global Infrastructure
AWS has **32 geographic regions** worldwide, each with multiple Availability Zones for reliability.

## Cloud Management Console
Manage all services at **console.aws.amazon.com**

## Four Core Services
1. **Amazon EC2** — Virtual computers in the cloud
2. **Amazon S3** — Unlimited file storage
3. **Amazon RDS** — Managed databases
4. **Amazon VPC** — Private cloud networking

## Three Advantages
1. Widest selection of services
2. Free Tier available for learning
3. Scales from tiny startup to huge company

## Typical Enterprise Use Cases
- Websites and mobile apps
- Big data analytics
- Global e-commerce and streaming
