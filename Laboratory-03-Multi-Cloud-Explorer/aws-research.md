# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's largest and oldest public cloud platform. It was launched by Amazon in 2006. AWS offers more than 200 services including computing, storage, databases, artificial intelligence, and networking. It is used by startups, governments, and very large companies all over the world.

## Global Infrastructure
AWS has **32 geographic regions** around the world. Each region has multiple locations called Availability Zones. This setup makes AWS fast and reliable almost everywhere on Earth.

## Cloud Management Console
You can manage everything through a website called the **AWS Management Console** at `console.aws.amazon.com`. This is where you create, view, and control all your cloud services.

## Four Core Services
1. **Amazon EC2** — Virtual computers (servers) in the cloud
2. **Amazon S3** — Unlimited storage for files, photos, videos, and data
3. **Amazon RDS** — Ready-to-use database servers
4. **Amazon VPC** — Your own private network in the cloud

## Three Advantages
1. AWS has the most services and features available
2. There is a Free Tier so you can try many services for free
3. It works well for companies of any size — from tiny startups to huge businesses

## Typical Enterprise Use Cases
- Running websites and mobile apps
- Storing and analyzing huge amounts of data
- Building global e-commerce and video streaming services
