## Questions & Answers

**1. Which cloud provider offers the broadest range of services?**
AWS offers the widest range of services. It has more than 200 services covering every category. Because AWS started earliest, it has had more time to build and add features than Azure or Google Cloud.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure is the best choice for Microsoft technologies. It was built to work directly with Windows Server, Active Directory, and Microsoft 365. Everything connects smoothly without rewriting anything.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in both areas. Google invented Kubernetes and created many AI technologies. Their cloud platform includes the best built-in tools for AI and container management.

**4. Which cloud platform would you personally choose and why?**
I would choose Google Cloud Platform for new and modern applications. It is clean, fast, and the leader in future technologies like AI and containers. If I worked at a school or Microsoft company, I would choose Azure instead.
