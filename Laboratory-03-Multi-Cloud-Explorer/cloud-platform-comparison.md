## Questions & Answers

**1. Which cloud provider offers the broadest range of services?**

AWS offers the widest range of services. It launched earliest in 2006 and now provides over 200 services across every category. It has more features, tools, and third-party support than Azure or GCP.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure is the best choice. It was built to work directly with Windows Server, Active Directory, and Microsoft 365. Everything connects smoothly without rewriting code or buying new tools.

**3. Which provider is strongest in AI and Kubernetes?**

Google Cloud Platform leads in both. Google invented Kubernetes and created many AI technologies. Their Vertex AI and GKE are the most mature tools in the industry.

**4. Which cloud platform would you personally choose and why?**

I would choose GCP for modern applications because it is clean, fast, and leads in future technologies like AI. If I worked at a school or Microsoft company, I would choose Azure instead.
