# Microsoft Azure Research

## Brief Overview
Azure is Microsoft's cloud platform, launched in 2010. It integrates perfectly with Windows, Microsoft 365, and Active Directory — making it the natural choice for Microsoft users.

## Global Infrastructure
**60+ regions** — available in more countries than any other cloud.

## Cloud Management Console
Manage all services at **portal.azure.com**

## Four Core Services
1. **Azure Virtual Machines** — Windows or Linux virtual computers
2. **Azure Blob Storage** — Store any amount of data
3. **Azure SQL Database** — Fully managed SQL databases
4. **Microsoft Entra ID** — User login and security

## Three Advantages
1. Works seamlessly with existing Microsoft tools
2. Easy hybrid connection to office servers
3. Same licenses often work — no extra cost

## Typical Enterprise Use Cases
- Schools, universities, government offices
- Companies using Windows and Office
- Businesses moving from on-premises to cloud
