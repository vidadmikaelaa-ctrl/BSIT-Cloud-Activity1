# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud platform, launched in 2010. It works perfectly with Windows, Microsoft Office, and other Microsoft tools. If a company already uses Microsoft products, Azure is the easiest choice.

## Global Infrastructure
Azure has **more than 60 regions** — more than any other cloud provider. It is available in more countries than AWS or Google Cloud.

## Cloud Management Console
Manage everything at the **Azure Portal** at `portal.azure.com`. It uses a simple dashboard with clickable icons and menus.

## Four Core Services
1. **Azure Virtual Machines** — Create Windows or Linux virtual computers
2. **Azure Blob Storage** — Store any amount of files and data
3. **Azure SQL Database** — Fully managed Microsoft SQL databases
4. **Microsoft Entra ID (Azure AD)** — Control who can log in and access services

## Three Advantages
1. Works perfectly with Windows, Office 365, and Active Directory
2. Easy to connect with existing office computers and servers
3. Same licenses often work — so you may not need to buy new ones

## Typical Enterprise Use Cases
- Companies already using Windows and Microsoft software
- Schools, universities, and government offices
- Businesses moving from their own server room to the cloud
