# Client Recommendations

## Client A — Startup Company
**Recommended Platform: AWS**

AWS is the best choice for a startup. It offers a Free Tier to start at no cost, and pay-as-you-go pricing that fits a limited budget. As the company grows, AWS scales infinitely. They could use:
- **Amazon EC2** — to run their mobile app
- **Amazon S3** — to store photos and user files
- **Amazon RDS** — to store user data in a database

## Client B — University
**Recommended Platform: Microsoft Azure**

Azure is the natural choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Everything works together without new tools or training. They could use:
- **Azure Virtual Machines** — to run school websites
- **Azure SQL Database** — to store student records
- **Entra ID** — same login system they already use

## Client C — AI Research Company
**Recommended Platform: Google Cloud Platform**

GCP is the leader in Artificial Intelligence and Machine Learning. It has the best tools and fastest computers for AI research. They could use:
- **Vertex AI** — to build and test AI models
- **Compute Engine (GPU)** — powerful computers for heavy calculations
- **Cloud Storage** — to store large research datasets

## Client D — Global E-Commerce Company
**Recommended Platform: AWS**

AWS has the most experience serving large global companies. It has regions worldwide and automatically scales during traffic spikes. They could use:
- **Auto Scaling Groups** — automatically add servers during sales
- **Amazon S3 + CloudFront** — fast product images worldwide
- **Amazon RDS Multi-AZ** — safe database that never goes offline

## Multi-Cloud Decision Matrix
| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Free Tier, low cost, grows as you grow |
| Enterprise Organization | AWS | Most mature, most services, trusted worldwide |
| Microsoft Environment | Azure | Works perfectly with Windows, AD, and Office |
| AI / Machine Learning | GCP | Best AI tools, built by Google AI experts |
| Kubernetes Deployment | GCP | Invented Kubernetes — most mature and standard |
| Global Web Application | AWS | Most regions, longest track record worldwide |
