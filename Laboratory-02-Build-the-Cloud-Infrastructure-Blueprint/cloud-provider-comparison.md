# Cloud Provider Service Comparison

## Equivalent Services Table
| Component | AWS | Azure | GCP |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage** | S3 / EBS | Blob Storage / Disk Storage | Cloud Storage / Persistent Disk |
| **Networking** | VPC | Virtual Network | VPC |
| **Identity & Access** | IAM | Entra ID / RBAC | Cloud IAM |

---

## Guide Questions

### 1. Broadest range of services?
**AWS** — oldest provider with most extensive global infrastructure and largest feature portfolio across every category.

### 2. Best for Microsoft product users?
**Azure** — integrates natively with Windows, Active Directory, and Office 365 with seamless authentication.

### 3. Best for AI, ML, and Kubernetes?
**GCP** — Google created Kubernetes and offers deeply integrated AI/ML tools optimized for their infrastructure.

### 4. Similarities across all three?
All three offer the same core categories — compute, storage, networking, identity — with pay-as-you-go pricing and virtualized resource models.
